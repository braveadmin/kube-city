# Kenney sprites

The sprites the browser view uses from two packs by Kenney (www.kenney.nl),
both public domain (CC0, see `License.txt` in each folder):

- `buildings/`: Isometric Buildings, https://opengameart.org/content/isometric-buildings-1
- `city/`: Isometric City, https://opengameart.org/content/isometric-city

File names and folders are the packs' own. Only the sprites that
`art/city.template.html` names (`"b001"` is `buildings/PNG/buildingTiles_001.png`,
`"c066"` is `city/PNG/cityTiles_066.png`, `"d010"` is `city/Details/cityDetails_010.png`)
are kept here. To use another sprite, copy it from the full pack into the same
place. kenney.nl refuses scripted downloads; the OpenGameArt pages work.
